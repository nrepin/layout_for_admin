# Страницы для админки

Набор готовых HTML-страниц для административных панелей. Их можно использовать как основу для собственных интерфейсов: менять оформление и содержимое, собирать новые страницы из существующих блоков и подключать данные своего проекта.

| Страница | Раздел |
| --- | --- |
| [index.html](index.html) | Аналитика |

## Как создать свой интерфейс

1. Откройте `index.html` или нужный пример в браузере.
2. Скопируйте подходящую HTML-страницу в корень проекта и измените её разметку.
3. При необходимости настройте стили и скрипты в `assets/css` и `assets/js`.
4. Замените демонстрационное содержимое данными своего проекта.

## SPA-навигация

В корне проекта запустите локальный HTTP-сервер:

```sh
python -m http.server 8000
```

Откройте [главную страницу](http://localhost:8000/). Внутренние ссылки обновляют область контента, адрес и заголовок вкладки. Шапка и боковое меню остаются в DOM. Прямые ссылки, обновление страницы и кнопки «Назад» и «Вперёд» работают с обычными HTML-адресами.

SPA-навигация находится в [assets/js/spa.js](assets/js/spa.js). Чтобы отключить её во всём проекте, установите `const enabled = false` в начале этого файла. Для отдельного шаблона удалите из него тег `<script defer src="./assets/js/spa.js"></script>`. Обычные ссылки продолжат открывать HTML-страницы целиком. При открытии файлов через `file://` этот режим используется автоматически.

Чтобы добавить страницу в SPA-навигацию, скопируйте подходящий шаблон, задайте уникальный идентификатор страницы в `page` и `data-admin-page` и добавьте ссылку в общее боковое меню. Сохраняйте контейнер с `data-admin-page` непосредственным потомком `#main-content`. Графики и карусели подключаются через цикл инициализации и очистки компонентов в общем скрипте.
