# Страницы для админки

Набор готовых HTML-страниц для административных панелей. Их можно использовать как основу для собственных интерфейсов: менять оформление и содержимое, собирать новые страницы из существующих блоков и подключать данные своего проекта.

## Примеры страниц

| Страница | Раздел |
| --- | --- |
| [index.html](index.html) | Аналитика |
| [crm.html](crm.html) | CRM |
| [ecommerce.html](ecommerce.html) | Интернет-магазин |
| [logistics.html](logistics.html) | Логистика |
| [marketing.html](marketing.html) | Маркетинг |
| [saas.html](saas.html) | SaaS |

## Как создать свой интерфейс

1. Откройте `index.html` или нужный пример в браузере.
2. Скопируйте подходящую HTML-страницу в корень проекта и измените её разметку.
3. При необходимости настройте стили и скрипты в `assets/css` и `assets/js`.
4. Замените демонстрационное содержимое данными своего проекта.
